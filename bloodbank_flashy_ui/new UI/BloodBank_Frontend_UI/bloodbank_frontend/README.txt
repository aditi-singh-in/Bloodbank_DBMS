BLOOD BANK MANAGEMENT SYSTEM - FRONTEND PROTOTYPE

This is a NON-FUNCTIONAL frontend/UI prototype for the DBMS project.
It intentionally uses dummy data. No MySQL, PHP backend, or API is required.

RUN:
1. Extract the ZIP.
2. Open the extracted folder in VS Code.
3. Double-click index.html OR use VS Code Live Server.
4. Login with ANY email/password (the login is demo-only).
5. Navigate through Dashboard, Donors, Recipients, Inventory, Requests, Donations and Reports.

TEAM INTEGRATION:
Frontend laptop -> Backend/API laptop -> Database laptop

When the backend is ready, replace the dummy JavaScript data/API actions in js/app.js with fetch() calls to your backend endpoints.

FILES:
index.html       Login
register.html    Registration UI
dashboard.html   Main dashboard
donors.html      Donor management
recipients.html  Recipient management
inventory.html   Blood inventory
requests.html    Blood requests
donations.html   Donation records
reports.html     Reports/analytics
css/style.css    Complete styling
js/app.js        Demo interactions + dummy data
